# SmartOps Product Website + Guided Room 305 Demo

## Website entry
Open `presentation/index.php` through XAMPP. The full Product Website remains unchanged.

## Live Demo flow
Click **Start Live Demo** in the website. It opens `presentation/guided_demo.php` in the same tab.

The demo uses an isolated visitor database and guides the visitor through:

1. Review the highlighted Room 305 HITL case.
2. Select a technician and approve the assignment.
3. Switch to Technician View.
4. Accept, start, and complete the task.
5. Return to Admin View to review the completion notification.

Use **Return to Product Website** to go back to the Live Demo section.

The demo database is separate from the real `smartstay_php` database. Apache and MySQL must be running.
